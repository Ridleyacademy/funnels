## Testing discipline (their playbook, applied)

- One control per lane, duplicated horizontally into new ad sets when scaling; refresh the video, keep the winning primary text.
- 3 to 5 primary-text variations per ad unit so Meta reports which message carries.
- Judge on cost per booked Session (Schedule/Lead per live-fix protocol), never CTR at low volume. Longevity is the winner signal.
- On-image copy gets the same review as text fields, and the on-image CTA must exact-match the destination page's button text.
